# AI-Powered Advanced Chatbot

A modern, responsive AI chatbot web application built with **React**, **Vite**, and **Tailwind CSS**. Developed as part of the Week 4 internship assignment.

## 🚀 Features

- **Interactive Chat Interface:** Clean, modern UI inspired by leading AI chat assistants.
- **Dynamic Sidebar:** Easily manage conversations, create new chat threads, and switch between sessions.
- **Simulated AI Responses:** Responsive mock intelligence that formats text and code snippets smoothly.
- **Fully Responsive:** Styled with Tailwind CSS for seamless viewing across desktop and mobile screens.

## 🛠️ Tech Stack

- **Frontend Library:** React (v18+)
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
